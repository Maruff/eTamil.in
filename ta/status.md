இ-தமிழ் இன்று சேவையக நிரல்களை இயக்குகிறது: செயல்கள், தொகுப்புகள், பிழைக் கையாளுதல்,
தொகுதிகள், SQL மற்றும் ஆவணத் தரவுத்தளங்கள், வழிச்செலுத்தலுடன் கூடிய ஒருங்கிணைந்த HTTP
சேவையகம், மேலும் இதே மொழியில் எழுதப்பட்ட கணக்கியல், வரி, வங்கி, காப்பீடு, சுங்கக்
கட்டமைப்புகள். இது உலாவியிலும் இயங்குகிறது — தொகுப்பி
WebAssembly-ஆகக் கட்டப்பட்டுள்ளது, எனவே இத்தளத்தின் எழுதுகளம் உண்மையானதே.

இந்த அட்டவணை நிரலின் நேர்மையான நிலை; விருப்பப் பட்டியல் அல்ல.

## தனித்தனியாக வைக்கப்பட்ட இரு எண்ணிடல் முறைகள்

இத்திட்டத்தில் தொடர்பற்ற இரு விஷயங்கள் "கட்டம் 1–N" என அழைக்கப்பட்டன. அவை முற்றிலும்
வேறுபட்டவை:

| சொல் | பொருள் |
|---|---|
| **கட்டுரைக் கட்டம் 1–5** | ஆய்வுத் திட்டவரைபடம்: தொகுப்பி மையம் → துறைத் தொகுதிகள் → கருவிகள்/REPL → முன்னோடித் திட்டங்கள் → கொள்கை ஈடுபாடு |
| **பின்தள மைல்கல் 1–4** | இக்களஞ்சியத்தின் HTTP வேலை: ஒத்திசைவு சேவையகம் → async → பதிவேடு → அங்கீகாரம் |

பின்தள மைல்கற்கள் 1–4 முடிந்திருப்பது கட்டுரையின் கட்டங்கள் பற்றி எதுவும் கூறவில்லை.
**கட்டுரையின் முறைப்படி இத்திட்டம் கட்டம் 2-இன் நடுவிலும் கட்டம் 3-இன் நடுவிலும்,
இரண்டிலும் ஒருசேர** உள்ளது; கட்டம் 1 முடிவுக்கு அருகில் — அதில் மீதமுள்ளவை
விடுபட்ட பகுதிகள் அல்ல, அறியப்பட்ட குறைகள்.

கட்டம் 2-இன் துறைத் தொகுதிகள் பெரும்பாலும் எழுதப்பட்டுவிட்டன: கணக்கியல், வரி, வங்கி,
காப்பீடு, சுங்கம், Fabric தணிக்கைத் தடம் — அனைத்தும் பேரேட்டின் மேல் இ-தமிழ் நூலகங்களாக.
கட்டம் 3-இல் தரவுதளங்கள், கருவிகள், இப்போது ஊடாடும் ஓடும் உள்ளன. கட்டம் 4 வெளியிடப்
பட்டுள்ளது, ஆனால் உண்மையான தயாரிப்பில் முன்னோடி எதுவும் நிறுவப்படவில்லை. கட்டம் 5 —
கொள்கை ஈடுபாடு — தொடங்கவில்லை; அது கட்டம் 2 ஒரு ஒழுங்குமுறையாளருக்குப் புரியும்
அளவுக்கு முன்னேறுவதைச் சார்ந்தது. பரிவர்த்தனைகளைக் கையாளும் GST தொகுதி அது அல்ல.

[ஆய்வில்]({{ '/ta/research/' | relative_url }}) விவரிக்கப்பட்டவற்றில் இன்னும்
வடிவமைப்பாகவே — நிரலாக அல்ல — உள்ளவை: GSTN வலைவாசல் இணைப்புகள், ITR மற்றும் TDS
வார்ப்புருக்கள், RBI/KYC தொடரியல்.

## பங்களிப்பு

இந்தப் பகுதி முன்பு பட்டியலிட்ட நான்கும் முடிந்தன: பெயரிடப்பட்ட தரவுதளக் கைப்பிடிகள்,
`செயல்`-க்கு அறிவிக்கப்பட்ட அளபுரு மற்றும் திரும்பு வகைகள், எழுத்துப்பெயர்ப்புச் சுத்தம், மேலும்
`மறை`-க்குப் பின்னால் மறையாக்கம். முன்னர் அங்கிருந்த சங்கேதம் பலவீனமான
செயலாக்கம் அல்ல, அணுக முடியாத இறந்த நிரல் — எனவே முதலில் நீக்கப்பட்டு,
பின் உண்மையான ஒன்றால் மாற்றப்பட்டது.

இப்போது மிகவும் பயனுள்ளவை:

- **உலாவியில் அங்கீகாரமும் ODF-உம்.** உலாவி கட்டுமானம் மறுக்கும், ஆனால்
  மறுக்க வேண்டியதில்லாத இரண்டு இவை. bcrypt-இன் சமவாய்ப்பு மூலம்
  வலைப்பக்கத்தினுடையதைச் சுட்ட வேண்டும்; ODF எழுதுபவர் மற்ற எல்லாக் கோப்புக்
  கூற்றுகள் போல `vm::host` வழியாகச் செல்ல வேண்டும் — அதற்கு host-இல்
  பைட்டுகளைப் படிக்கும் வழி தேவை, இதுவரை தேவைப்படாத ஒன்று. தரவுதளங்கள்,
  Redis, HTTP சேவையகம் வேறு — அவை மறுத்துக்கொண்டே இருக்கும்:
  வலைப்பக்கத்திற்கு இணைப்பு இல்லை.
- **LLVM பின்தளத்தின் கூற்றுகள்.** கோவைகள் முழுமை; கோப்புகள், தரவுத்தளங்கள், HTTP, வழிகள்
  மறுக்கப்படுகின்றன. `scripts/run_parity.sh` ஒவ்வொரு நிரலுக்கும் மீதமுள்ள தனித்த காரணங்களின்
  எண்ணிக்கையால் தரவரிசைப்படுத்துகிறது, எனவே அடுத்து எதைச் செய்வது என்பது ஊகமல்ல, அளவீடு.
- **உண்மையான பலகைகளில் artino.** எல்லாம் பலகையின் மாற்று ஒன்றுக்கு எதிராகவே
  சோதிக்கப்பட்டுள்ளது. `examples/artino` ஐ இயக்கும் ஒரு Uno, Mega அல்லது Pico இலிருந்து,
  அல்லது உண்மையான முனைகளுடன் `nUlakam/vaZporuL/vaZporuL_cOqaZY.qmz` ஐ இயக்கும்
  Raspberry Pi இலிருந்து ஒரு அறிக்கை, போலியாக்கம் தீர்க்க முடியாததைத் தீர்க்கும்.
